I build the path from satellite data to something a person can use: processing pipelines, models, APIs and interactive maps. My background is geodesy and cadastral surveying in Kabul, followed by an MSc at Politecnico di Milano. My thesis traced Italian land cover change from 1985 to 2022 and projected it to 2032 with a constrained Markov chain.
